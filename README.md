## 🏨 Key Website Features

* **Authentic Heritage Visual Identity:** Custom Rajasthani palette (`Forest Green #183D2B`, `Warm Ivory #F8F6F0`, `Sand Beige #E8DFCF`, `Muted Gold #B99A62`) paired with regal *Cormorant Garamond* headings.
* **Authentic Property Photographs:** 5 verified high-resolution photographs showcasing the exterior scalloped arches, mountain pool view, guest room interior, and aerial property perspective.
* **Direct WhatsApp Booking Engine:**
  * Interactive booking modal and in-page direct enquiry form.
  * Date validation (disallows past dates and enforces check-out after check-in).
  * Room category pre-selection from accommodation cards.
  * Generates formatted, URL-encoded WhatsApp messages directly to resort management (+91 96363 52306).
* **Interactive Lightbox Gallery:** Filterable by categories (*All*, *Exterior*, *Rooms*, *Pool*, *Property Views*) with keyboard navigation (`ESC`, `ArrowLeft`, `ArrowRight`).
* **Explore Pushkar Guide:** Curated distance estimates and Google Maps navigation to Savitri Temple & Ropeway, Pushkar Lake, Brahma Temple, and the Desert Dunes.
* **Mobile-First Responsive Experience:** Verified across all device widths from 320px to 1440px+, featuring a sticky mobile booking & tap-to-call action bar.
* **Technical SEO & Structured Data:** Semantic HTML, meta tags, Open Graph, Twitter Cards, XML Sitemap, Robots.txt, and Schema.org `Resort` / `LodgingBusiness` JSON-LD.

## 🛠️ Getting Started

### Prerequisites
* Node.js (v18+ recommended)
* npm

### Installation
```bash
# Clone the repository
git clone https://github.com/krinectra17-bit/Parvat-Valley-Resort.git
cd Parvat-Valley-Resort

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build & Preview
```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```
